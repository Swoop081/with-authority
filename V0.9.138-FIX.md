# v0.9.138 Fix

## Original location checks

`WAGetLocation` now returns the same resolved location representation as `WAFindLocation`.

This fixes original scripts such as Throw Over The Ropes:

- legal when the target is at `InTheRing`;
- grounded/standing is a separate position state and does not change ring location;
- after the move connects, its original script may move the target to Ringside.

## Live card backs

The hand-card inner container is no longer rotated when flipped. The front and back faces are
switched explicitly, preventing iOS Safari from mirroring or reversing back text.
