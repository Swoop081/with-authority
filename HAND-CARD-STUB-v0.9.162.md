# v0.9.162 Hand Card Layout

The red Play Page / legality message is now a separate stub below each hand card.

The actual card:
- keeps a fixed 5:7 trading-card ratio;
- no longer shares its height with the red message;
- shows contained artwork without being squeezed;
- retains tap-to-flip and swipe handling.

The stub remains tappable for Play Page or for displaying the legality explanation.
