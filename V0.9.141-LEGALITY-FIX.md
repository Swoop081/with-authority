# v0.9.141 Legality Fix

## Submission pages after Momentum

The original game treats Submission pages as Move Pages. The recreation's post-Momentum
gate only accepted `Move` and `Trademark`, incorrectly blocking Headlock.

The player and CPU now use the same `isMovePage()` definition, including Submission pages.

## On-mat original-script checks

Original scripts such as Fist Drop use `WAGetOnMat #target`. The adapter previously returned
a stale per-side `false` value even when the live match position visibly showed Grounded.

`WAGetOnMat` now resolves the current target's actual live Grounded/Prone/Victim Below state.

## Austin Agility evidence conflict

The authentic Starter-StoneCold deck contains four Agility pages, while original `stsa.gac`
contains `Agility_Maximum = 0`. This patch does not alter that original value until executable
behaviour is confirmed.
