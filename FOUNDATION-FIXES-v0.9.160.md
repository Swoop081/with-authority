# v0.9.160 Foundation Fixes

- Momentum pages use `momentumType` for colour, so Technical is green and each
  other method uses its own authentic method colour in every screen.
- Lift Into Post and other cards with the exact printed Ringside wording are
  blocked unless both wrestlers are at Ringside.
- Reaching 0 HP no longer causes a fabricated knockout victory.
- A wrestler at 0 HP remains in the match and must still lose by pinfall,
  submission, count-out, disqualification or the configured turn-limit result.
- Card faces retain a 5:7 trading-card silhouette.
- Artwork uses `object-fit: contain` so the source image is not cropped.
